## S1 report summary (design system API)

- **Colours:** every token in `docs/design.md` exists in light and dark. Existing names keep new values; the new ones are `surfaceAlt`, `graphite`, `stone`, `cloud`, `mint`, `marigold`, `periwinkle`, `pastelInk` and `papaya`. Also new: types `PastelToken` and `skyGradient`.
- **Radii:** `panel` 20, `hero` 24, `sheet` 24, `button` 14, `field` 14, `chip`/`pill` 9999, `swatch` 6, `cell` 2.
- **Spacing:** the existing keys plus `gutter` 20, `card` 24, `cardNarrow` 20, `cardGap` 20 and `narrowWidth` 360. `useCardPadding()` returns 24, or 20 on narrow screens.
- **Type:**
  - `Text` variants: `display` (46 serif, tabular), `title` (34 serif), `subtitle` (24 serif), `heading`, `body`, `label`, `hint`, `caption`. `rowNumber` is an alias of `display`.
  - Passing `weight` to `Text` picks a sans face, so it turns a serif variant into sans. Don't pass `weight` on serif variants.
  - `theme.fonts` has `regular`, `medium`, `semibold`, `bold` and `serif`.
- **Shadows:** `theme.shadows.float`, `.lift`, `.bar` (points up, for bars), `.segment` and `.none`. Each is a `{ boxShadow }` style to spread.
- **Cards:** `theme.cards.card`, `.hero` and `.well` are ready-made surfaces with no padding; add `useCardPadding()`. They get a border in dark mode only.
- **Components:**
  - `Button`: primary is an ink pill (48 high; 52 with `size="lg"`); default is radius 14 with a border; link is underlined.
  - `Chip`: `tone` includes `mint`, `marigold` and `periwinkle`. The Finished pill is `<Chip tone="mint" icon="check" />`.
  - `TextField` is new in `@/ui`, with the same API as the local one in `features/projects/parts.tsx` plus `maxLength`, `autoCapitalize`, `invalid`, `tabular` and `style`. **Replace the local one with it.**
  - `EmptyState` takes `paper?: PaperColor` and `paperSeed`.
  - `PaperShape({ color, width, height, seed, rotate, dots, shadow, style })` is absolutely positioned, ignores touches and is hidden from accessibility. `Screen` now clips horizontally.
  - `Screen` uses gutter 20 and top padding 8. `Header` has 20 bottom margin.
  - `StripScroller` takes `well` (default true). Drawdown and PicturePreview sit in wells with a papaya current-row frame.
- **Fonts:** the npm install of Lora and Inter was blocked by the sandbox's permission system. Until the owner allows it, sans renders in Familjen Grotesk and the serif falls back to the system serif. Don't try to install them. Swapping fonts later touches only `src/ui/fonts.ts`.
- **Known screen issue to fix:** at 390 px the library grid shows **one column**; it must be two columns on phones (cards about 160–175 px wide), and more on wider screens.
