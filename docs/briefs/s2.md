## Do

1. **Every screen:** Stitches library, stitch detail, setup sheet, pattern guide, picture guide, Projects, Settings, the not-found screens, and the legacy import offer.
   - Remove local hard-coded styling that fights the new system: borders on cards, old radii, `fontWeight` on text, colour literals.
   - Use the theme's variants, tokens and shadows.
   - Screen titles use the serif `title` variant; the stitch name on the detail page uses `subtitle`; "Row N" and "Finished" use `display`.
   - Library cards become white floated cards (`float` shadow, radius 20) with the preview inset at radius 14.
   - The Quick start and Continue card becomes a hero card with a PaperShape behind one corner.
   - Projects rows become one floated card list, or one card per row: choose whichever looks cleaner and say which.
   - Primary actions ("Start weaving", "Row done", "Bring it over", "New from picture") are pills.
   - "Finished" in the projects list and the picture guide uses the mint pill.
2. **PaperShapes:** place them only where the spec allows, at most two per screen. None in the guides.
3. **Spacing:** apply the spec's gutter, card padding and gaps. Check 320 px, 390 px and 1280 px widths for overflow, and 200 % zoom.
4. **App identity:**
   - Regenerate the icon, favicon, splash and Android adaptive layers with `e2e/tools/make-icons.mjs` per the spec's "App identity" section.
   - Update the splash and adaptive background colours in `app.json`, and the PWA manifest and `theme-color` values in `scripts/export-web.mjs`.
5. **Tests:**
   - `npm run check`, `npm run e2e` and `npm run e2e:pwa` must all be green.
   - Update any test that asserted an old style value, keeping what it checks. Never delete or skip one.
   - If an e2e assertion checks colours or contrast, point it at the new tokens.
6. **Screenshots:**
   - Regenerate `docs/screens/` with `e2e/tools/screens.mjs` (light and dark, phone size).
   - Add a `docs/screens/desktop-library-light.png` at 1280×800.
   - Look at every one yourself and fix what looks off before you finish.
7. **Docs:** update the design section of `README.md` if it describes the old look.
