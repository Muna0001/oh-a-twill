## PictureGuide (PLAN 3.5)

A scrolling `Screen` with the `BottomBar` as the non-scrolling footer.

- `Header`: project name, back (fallback `/projects`).
- **Warp threads first**: a `Panel` with a `Stepper` 4–120 and the hint "Your picture will be N squares wide".
- **Picture panel**, no picture: icon, "Add a picture", the reference hint ("Bold shapes on a plain background work best, like a single flower. Your picture stays on this device."), a "Choose a picture" button (`pickPicture('library')`) and, on native only, "Take a photo" (`pickPicture('camera')`). On web also accept drag and drop of an image file onto the card (`importPictureFile`), with the DOM handling kept in this folder behind a `Platform.OS === 'web'` check. Errors show the reference messages via `messageFor` in a warning box.
- **Picture panel**, with a picture: "Use another" link button, thumbnail, "W warps by H rows, K yarn colors", the palette list (swatch, name, "N squares"), the how-it-works hint (the two reference sentences, by weave), and settings: Weave `Segmented` (2/2 twill / Plain weave), Colors `Stepper` 2–8, Rows `Stepper` 4–400 with a "Match the picture’s shape" link shown when rows is set and differs from `autoH`, Cleanup `Checkbox` "Remove single-square specks".
- `usePictureGrid(project)`: calls `buildPicture` when imageUri, warps, rows, k or tidy change (debounce about 150 ms, ignore stale results; changing weave must not rebuild); exposes `{ pic, status: 'idle' | 'building' | 'ready' | 'error', error }`; keeps the previous grid visible while rebuilding with a small "Updating…" indicator; calls `clampPictureRow(id, H)` when a new grid arrives.
- **Row card** (hero `Panel`): "Row N" with "of H" small, "k section(s)" pill, the sub line ("Same colors as the last row." when `sameAsPrevious`, else "Weave each section across and back with its color."), `StripScroller` with `PictureStrip` + `WarpNumbers`, `SectionChips`, "Back to row 1" when row > 1. When row > H: "Finished", "All H rows are woven. Nice work." and "Back to row 1".
- **Woven preview** panel: heading, the reference hint, `PicturePreview` with tap-to-jump.
- `BottomBar`: Back (disabled at row 1 or with no picture), centre "Row N" or "Finished" (empty with no picture), primary "Row done" (disabled when finished or with no picture) → `nextRow(id, H + 1)`.
- Call `open(projectId)` once on mount.
