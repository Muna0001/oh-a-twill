## ProjectScreen

Dispatches by kind to `PatternGuide({ projectId })` from `@/features/guide` and `PictureGuide({ projectId })` from `@/features/picture` (other agents are replacing those placeholders now; import them by those names). Unknown id → `EmptyState` with a button to `/projects`.

## ProjectsScreen (PLAN 3.6)

- Title "Projects"; "New from picture" (creates a picture project with `Settings.defaultWarps`, opens it, navigates to `/project/<id>`) and "New from a stitch" (goes to `/`).
- Rows in store order: thumbnail (`TilePreview` with the project's colours and mirror for pattern projects; the picture via `thumbnailSource` for picture projects, or a photo icon when it has none), name, a status line ("Row 37 · 24 warps"; "No picture yet" for pictures without an image), the last-woven date in a short local format. Tapping opens the project.
- Each row has a "more" button (ellipsis) opening a `Sheet` with Rename (text field), Duplicate, Delete (confirm: "Delete “name”? This can’t be undone.").
- Empty state pointing to the Stitches tab and "New from picture".

## ProjectSetupScreen

One screen for new projects (`stitchId` given; nothing is created until the primary button is pressed) and existing pattern projects (`projectId` given; changes apply as you make them, under the store's reset rules; when the project is past row 1, note under "Start on" that changing it goes back to row 1). `Header` with a close button. In this order:

1. Stitch summary: a `TilePreview` that reflects the chosen colours and mirror, name, description. For an existing project, a small note that a different stitch means a new project.
2. **Warp threads** `Stepper` 4–120, first among the controls, with the fit hint under it in the reference's words ("6 repeats of 4, clean edges" / "5 repeats of 4, plus 2 extra"; `repWidth` includes colour repeats).
3. **Start on**: one button per tile row named by `tileRowName` (hidden when the tile has one row).
4. **Yarn colors**: `ColorField` "Color A" and "Color B"; for colour-and-weave stitches the "Wind the warp in this order, then repeat: …" line.
5. **Direction** `Segmented` (As shown / Mirrored).
6. **Row 1 starts at the** `Segmented` (Left edge / Right edge).
7. Optional name field (defaults to the stitch name).
8. Primary button: new → "Start weaving" (`createPattern` with the chosen values, `open(id)`, `router.replace('/project/<id>')`); existing → "Done" (`router.back()`, falling back to `/project/<id>`).

Unknown stitch or project → `EmptyState`. A picture project id → a short note that picture settings are on the picture screen, with a button back.

## SettingsScreen

Title "Settings"; default warps (`Stepper`), default start edge (`Segmented`), default yarn colours (two `ColorField`s), haptics (`Checkbox`, noting it applies to phones), keep the screen awake while weaving (`Checkbox`), theme (`Segmented` System / Light / Dark; writing to the settings store is enough, the root layout syncs it to the UI theme), and an About panel: app name, version (from `expo-constants` if straightforward in SDK 58, otherwise a constant), and "Everything stays on this device. Your pictures are never uploaded, and nothing is tracked." plus "Your projects are saved on this device only."
